Operation ID: getConsumptionHistoryPerBranchV2.

Authentication: bearer token (BearerAuth) or API key in the cookie (CookieAuth) or API key in the cookie (TokenCookieAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | cursor | query | string | No | Cursor from the previous response (pagination.cursor). Default: 100. | | project_ids | query | array of string | Yes | Project IDs to include (required, 1 to 100). Returns metrics for branches in these projects.
