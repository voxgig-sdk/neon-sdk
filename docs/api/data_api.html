Parameters

Request body

application/json

Property Type Required Description
add_default_grants boolean No Grant all permissions to the tables in the public schema to authenticated users
auth_provider enum: neon_auth, external No Authentication provider for the Neon Data API. neon_auth: use Neon's built-in managed authentication (no JWKS configuration required). external: use an external JWT provider, which requires jwks_url. When omitted, no auth provider is configured (existing setup is kept).
jwks_url string (uri) No URL of the JWKS endpoint used to verify JWTs for this Data API. Required when configuring JWT-based authentication; omit when using a non-JWT auth provider.
jwt_audience string No Expected aud claim in incoming JWTs. When set, tokens with a different audience are rejected; tokens with no audience are still accepted. Omit to skip audience validation.
provider_name string No Display name for the authentication provider. Accepted values include "Clerk", "Stytch", and "Auth0", but any non-empty string is valid. Optional field.
settings object No Auth and schema configuration for the Data API.
settings.db_aggregates_enabled boolean No Enable aggregates feature
settings.db_anon_role string No Database role to use for anonymous requests
settings.db_extra_search_path string No Extra schemas to add to the search path
settings.db_max_rows integer No Hard limit on the number of rows returned in a single Data API response. No limit when unset.
settings.db_schemas array of string No List of schemas to expose via the API. Default: ["public"]
settings.jwt_cache_max_lifetime integer No Maximum lifetime of the Data API's JWT cache, in seconds.
settings.jwt_role_claim_key string No JWT claim key to use for role extraction
settings.openapi_mode string No OpenAPI specification mode (ignore-privileges, disabled)
settings.server_cors_allowed_origins string No CORS allowed origins
settings.server_timing_enabled boolean No When enabled, the Data API adds Server-Timing headers to each response showing database execution and internal processing time. Default: disabled.
skip_auth_schema boolean No Skip creating the auth schema and RLS functions
