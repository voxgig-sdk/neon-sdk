POST /projects/{project_id}/branches/{branch_id}/restore

Operation ID: restoreProjectBranch.

Authentication: bearer token (BearerAuth) or API key in the cookie (CookieAuth) or API key in the cookie (TokenCookieAuth).

Parameters

| Parameter | In | Type | Required | Description | | --- | --- | --- | --- | | project_id | path | string | Yes | The Neon project ID | | branch_id | path | string | Yes | The branch ID |

Request body

application/json

Property Type Required Description
preserve_under_name string No Name under which to save the current branch state before restoring. Required when the branch has children or when source_branch_id equals the branch being restored; in those cases all existing child branches are moved to the newly created branch. If omitted and not required, the previous state is not preserved.
source_branch_id string Yes The branch_id of the restore source branch. If source_timestamp and source_lsn are omitted, the branch will be restored to head. If source_branch_id is equal to the branch's id, source_timestamp or source_lsn is required.
source_lsn string No A Postgres LSN (for example, 0/1A2B3C4) on the source branch to restore from. Mutually exclusive with source_timestamp. Omit both to restore to head.
source_timestamp string (date-time) No A point in time on the source branch to restore from, in RFC 3339 format. When omitted alongside source_lsn, the branch is restored to the latest available state of the source branch.
